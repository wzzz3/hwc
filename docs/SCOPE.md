# 库存中心独立版范围

## 本期交付范围

本项目仅迁移现有经营看板中的库存中心，不包含销售、广告、资金、物流或钉钉功能。

- 平台库存：Amazon、Walmart、TikTok、TEMU 的库存展示、筛选、排序和 SKU 查询。
- 海外仓库存：仓库清单、库存明细、历史、导入、导出以及平台关联。
- 库存数据管理：SQLite 存储、数据来源批次、原始导入文件本地保存和导入核验。
- 库存分析：可售、在途、不可售、近 30 天销量、预计可售天数和数据配对异常。

## 不在本期范围

- 若依登录、菜单、权限和 API 对接。
- 销售、广告、资金、物流、钉钉通知与汇率业务。
- 对 Amazon、Walmart、TikTok、TEMU 或海外仓的写回操作。

## 兼容原则

页面继续使用现有库存中心的静态资源和视觉风格。独立部署时使用 Node.js 22 和 SQLite；未来接回若依时，应以库存 API 的响应结构为适配边界，而非把若依代码复制进本项目。
